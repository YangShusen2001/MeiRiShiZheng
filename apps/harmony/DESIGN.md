# 考公云鸿蒙端 · 设计规范

> 唯一事实源：`entry/src/main/ets/theme/Tokens.ets`。**页面里不允许出现硬编码色值、字号、间距。**
> 新增视觉需求 → 先在 Tokens 加令牌 → 再在页面引用。
> 校验脚本（本文件末尾）可自动检出违规。

---

## 1. 设计定位

**暖米底 + 深绿的「护眼阅读」调性。** 与 Web 端**有意不共用色板**：

| | Web 端 | 鸿蒙端 |
|---|---|---|
| 底色 | `#f5f7fa` 冷灰蓝 | `#F5F1E8` 暖米 |
| 主色 | `#1d4ed8` 品牌蓝 | `#4C795B` 深绿 |
| 取舍 | 信息密度优先、品牌识别 | **长时阅读的暖调与低蓝光** |

理由：考公复习动辄单次 30 分钟以上的连续阅读，暖底 + 低饱和绿能显著降低视觉疲劳；
Web 端面向浏览与检索，保留品牌蓝更合适。这是**有意的分化**，不是不一致。

> 若将来要让 Web 也走暖调，Web 已有 `[data-theme="reading"]`（`#f6f1e6` / `#8a5a2b`），
> 可作为对齐的落点——但那是 Web 侧的决策，不在本规范范围。

## 2. 颜色令牌与对比度审计

所有比值均为**按 WCAG 2.1 相对亮度公式实算**，非估计。

### 底色与容器

| 令牌 | 值 | 用途 |
|---|---|---|
| `BG` | `#F5F1E8` | 页面底色 |
| `SURFACE` | `#FFFFFF` | 卡片/内容容器 |
| `SURFACE_ALT` | `#FAF7F0` | 次级容器（图例底、内嵌区块） |

### 文本三级（含对比度）

| 令牌 | 值 | 对 SURFACE | 对 BG | 结论 |
|---|---|---|---|---|
| `INK` | `#1F2937` | **13.90:1** | **13.02:1** | ✅ AAA |
| `SUB` | `#5F6875` | **5.64:1** | **5.00:1** | ✅ AA（两底通用） |
| `MUT` | `#6A7280` | **4.85:1** | 4.30:1 | ✅ AA（⚠️ **仅限 SURFACE 之上**） |

> **修正记录**：首版用 `#9CA3AF` 做次要信息，白底仅 **2.54:1**（远不达 AA）；
> `#6B7280` 在暖底 4.29:1（差 4.5 一点点）。现取值是**保持原色相前提下加深**，不是换色。
> `MUT` 在暖底仍不足 4.5，故规定它只用于白卡内。

### 描边

| 令牌 | 值 | 说明 |
|---|---|---|
| `LINE` | `#E6DFD0` | 主描边。**带暖调**——首版用冷灰 `#E5E7EB` 压在暖底上，色温冲突 |
| `LINE_SOFT` | `#F0EADD` | 卡片内浅分隔 |

### 品牌绿

| 令牌 | 值 | 用途 | 对比度 |
|---|---|---|---|
| `PRIMARY` | `#4C795B` | 填充、图标、大色块 | 5.01:1 on SURFACE |
| `PRIMARY_TEXT` | `#456F53` | **小字号文本专用** | 4.89:1 on `PRIMARY_SOFT` |
| `PRIMARY_SOFT` | `#E6EFE8` | 胶囊标签底 | — |

> `PRIMARY` 直接压在 `PRIMARY_SOFT` 上只有 **4.26:1**，小字不达 AA。
> 所以浅绿底上的文字必须用 `PRIMARY_TEXT`。

### 语义与标注

| 令牌 | 值 | 用途 |
|---|---|---|
| `DANGER` / `DANGER_SOFT` | `#B91C1C` / `#FEF2F2` | 错误态 |
| `WARN_INK` / `WARN_SOFT` | `#8A5A0B` / `#FDF3DF` | 提示条（未收录原文等） |
| `HINT_SOFT` | `#FFFBEB` | 释义浮层底 |
| `NEUTRAL_SOFT` | `#ECEFF3` | 中性胶囊（关闭按钮等） |
| `SKELETON` | `#EFEBE1` | 骨架屏 |
| `SCRIM` | `#33000000` | 浮层遮罩（**轻遮罩**：重遮罩会让暖底界面显脏） |
| `ANN_EXAM` | `#FFE7A0` | 考点高亮 |
| `ANN_VIEWPOINT` | `#C8E6C9` | 观点高亮 |
| `ANN_TERM` | `#BBDEFB` | 术语高亮 |
| `ANN_FIGURE` | `#F8BBD0` | 数字指标高亮 |

**标注配色审计**：四色均为浅底 + `INK` 深字，`INK` 压在其上分别为
12.02 / 10.45 / 10.5 / 11.4:1 —— **全部远超 AA**，可放心用作长段高亮。

### 深色令牌（v1.1 新增）

**为什么不做反色**：`#F5F1E8` 直接取反会得到脏灰，暖调尽失；
纯黑底配暖色文本夜间反光过强。所以深色是**另一套独立取值的"深暖灰"体系**，
文字用暖白 `#EDE8DE` 而非 `#FFFFFF`（纯白在暗底上会有眩光拖影）。

| 令牌 | 深色值 | 对深底对比度 |
|---|---|---|
| `BG` | `#1A1815` | — |
| `SURFACE` / `SURFACE_ALT` | `#242220` / `#2C2A26` | — |
| `INK` | `#EDE8DE` | **14.43:1** ✅ AAA |
| `SUB` | `#B8B2A6` | **8.36:1** ✅ AAA |
| `MUT` | `#948E82` | **5.42:1** ✅ AA |
| `PRIMARY` | `#7FB08F` | **7.14:1** ✅（浅色的 `#4C795B` 在暗底只有 2.6:1，必须提亮） |
| `PRIMARY_TEXT` | `#8FBC9C` | **5.90:1** on `PRIMARY_SOFT` ✅ |
| `LINE` / `LINE_SOFT` | `#3A3732` / `#2F2C28` | — |
| `SCRIM` | `#80000000`（浅色是 `#33000000`） | 暗底需更重才压得住 |

**标注四色在深色下换暗底 + 暖白字**（浅底在暗环境会眩光；`INK` 压在各暗底上 8.6–10.4:1）：

| 类型 | 浅色 | 深色 |
|---|---|---|
| 考点 | `#FFE7A0` | `#4A3E1C` |
| 观点 | `#C8E6C9` | `#22402B` |
| 术语 | `#BBDEFB` | `#1E3547` |
| 数字指标 | `#F8BBD0` | `#43242E` |

## 3. 排版 / 间距 / 圆角 / 动效

### 字号（比例约 1.2，以正文 17 为基准）

| 令牌 | 值 | 用途 |
|---|---|---|
| `CAPTION` | 12 | 序号、角标 |
| `META` | 14 | 来源、日期、标签 |
| `BODY` | 17 | 正文（阅读页） |
| `TITLE_S` | 20 | 卡片/列表标题 |
| `TITLE_M` | 24 | 区块标题 |
| `TITLE_L` | 28 | 文章标题 |

> 首版为 12/13/14/15/16/17/22 —— **7 档无比例关系**，13/15 为编外值，已全部归位。

### 行高

`TIGHT 22`（配 META）· `NORMAL 24`（配 BODY 概览）· `RELAXED 30`（配 BODY 正文，1.76 倍）
· `DISPLAY 38`（配 TITLE_L）

### 字号与行高（v1.1 起支持阅读档位）

标尺以正文 17 为基准，比例约 1.2：`12 / 14 / 17 / 20 / 24 / 28`。

**档位系数**：小 `0.88` · 标准 `1.0` · 大 `1.15` · 特大 `1.3`

**缩放策略（关键）**：

| 类别 | 是否缩放 | 理由 |
|---|---|---|
| 正文、卡片标题、文章标题（`body` / `titleS` / `titleL`） | ✅ 缩放 | 这是阅读密度，用户要调的就是它 |
| 角标、来源、日期、标签（`caption` / `meta`） | ❌ 固定 | 放大后会挤压导航与元信息，反而不易读 |
| 区块标题（`titleM`） | ❌ 固定 | 避免与列表行抢空间 |

**行高必须联动**：`lineHeight = fontSize × 系数`（正文 1.76、概览 1.41、角标 1.57、标题 1.36）。
只放大字号不放大行高，中文会挤成一团。

**为什么用离散档位而不是滑杆**：阅读排版需要可预期的结果（行高、折行位置），
滑杆会造出无数中间态，用户反而找不到合适的阅读密度。

### 间距（4 的倍数）

`HAIR 2` · `XS 4` · `S 8` · `M 12` · `L 16` · `XL 20` · `XXL 24` · `XXXL 32` · `PAGE 16`

> 首版散落 2/6/10/13/14/18/21/26 等编外值（44 处魔数），已归位。

### 圆角

`XS 4` · `S 8` · `M 10` · `L 14`（卡片）· `XL 20`（浮层顶角）· `FULL 999`（胶囊）

### 动效

`XS 120` · `SM 160` · `MD 250` · `LG 400`（ms，与 Web 端档位一致，便于跨端节奏统一）

## 4. 组件约定

| 组件 | 规格 |
|---|---|
| **卡片** | `SURFACE` + `KSpace.L` 内边距 + `KRadius.L` + 暖调阴影（`KShadow.CARD_*`） |
| **胶囊标签** | `FULL` 圆角，水平 `KSpace.L` 内边距，**触摸目标高度 44** |
| **列表行** | 整行可点，`constraintSize({ minHeight: 44 })`，按压态 `SURFACE → SURFACE_ALT` |
| **图例 chips** | 用标注色做底 + `INK` 字；**图例不承担点击**，点击交给右侧「标注清单」 |
| **底部浮层** | `HINT_SOFT` 底 + 顶部双圆角 `XL` + 外层轻遮罩，**遮罩整屏可点关闭** |
| **设置面板** | `view/SettingsSheet.ets` 可复用组件；含字号档位 + 深色开关 + **实时预览行**；面板只负责内容，浮层容器由调用方提供 |
| **错误态** | 白卡 + `DANGER` 标题 + `SUB` 说明 + 44 高「重试」按钮（**不白屏**），措辞区分「没联网 / 服务异常 / 未部署」 |
| **骨架屏** | 结构与真实卡片一致，避免内容到达时的布局跳动 |

### 无障碍硬指标（已落地）

- 交互元素高度 **≥44vp**（日期胶囊、列表行、图例、清单条目、按钮已全部满足）
- 文本对比度：正文与次要信息均 ≥4.5:1（见 §2）
- 不依赖颜色单独传达信息：标注除底色外**同时**有类型文字标签

## 5. 交互清单

### 本轮补齐（相对首版）

| # | 缺口 | 处置 |

### v1.1 补齐（本轮）

| 优先级 | 项 | 实现方式 |
|---|---|---|
| P0 | **深色模式** | 独立的深暖灰令牌体系（非反色）；`Settings` 持久化 + `setColorMode` 同步系统组件 |
| P0 | **字号调节** | 四档（小/标准/大/特大），行高联动；**面板内带实时预览**，避免盲调 |
| P1 | **阅读进度** | 底部细进度条（轨道 + 填充）+ 头部「已读 xx%」 |

| P1 | **上一篇 / 下一篇** | 路由携带当日文章列表，阅读页自行算邻居；`replacePathByName` 保持栈深不变 |
| P2 | **标注类型筛选** | 图例即可点筛选；选中态**除颜色外另有加粗**（不靠颜色单独表意）；类型选满自动回「全部」 |
| P2 | **复制原文链接** | 系统剪贴板（零权限、零配置），放在来源行旁；成功/失败都有反馈 |
| P2 | **离线感知** | 失败时先探测默认网络（`connection.getDefaultNet`），区分「没联网」与「服务异常」 |

## 6. 违规自检脚本

```bash
cd apps/harmony/entry/src/main/ets
python -c "
import os,re
bad=[]
for dp,_,fs in os.walk('.'):
    for f in fs:
        if not f.endswith('.ets'): continue
        p=os.path.join(dp,f)
        if p.endswith('Tokens.ets'): continue
        src=open(p,encoding='utf-8').read()
        for m in re.finditer(r'#[0-9A-Fa-f]{6,8}', src):
            bad.append(f'{p}: 硬编码色值 {m.group(0)}')
print('硬编码色值:', len(bad) or '0 ✓')
[print(' ',b) for b in bad]
"
```

期望输出：`硬编码色值: 0 ✓`
