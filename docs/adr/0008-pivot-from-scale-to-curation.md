# ADR 0008：从「规模聚合」转向「精选 + 记忆」——正式反转加量决策

- 状态：**已接受**（2026-08-22 用户拍板）
- 关联：`0008`（扩量调研）/ `0014`（扩池 30）——**本 ADR 反转这两项的加量目标**；`0022`（赛道转向提案）；`docs/product/card-refinement-rules.md`
- 日期：2026-08-22

## 背景

0008 调研的结论是"网页太少"（每天产出不足），落地为扩展来源/翻页与扩池到 30（0014）；之后每日实际产出 36-59 篇（`content/_reports/2026-08-19.json`：candidates 75 / articles 59）。

用户 2026-08-22 复盘：**每天文章太多，自己都看不完，用户更看不完；看完即忘、有印象不深入**——聚合规模不是价值，`记忆与深度` 才是备考产品的价值。

## 决策

1. **从「每日聚合（量优先）」转为「精选（2-5 篇）+ 考点记忆（卡片/复习）」**：候选池（75→）只用于选材，不再全部发布；每日发布上限 5 篇、下限 2 篇（不足时历史文章补剧）。
2. **每日学习目标由「主题轮换」改为「主线池跟踪」**：政策有连续性，一段时期并行/择一重；主线池人工维护（`content/policy-lines.json`），不做 AI 归纳。
3. **槽位制**：头版要闻（可脱离主线池）+ 申论精读 ×2 + 考点提炼 ×1 + 多样性补充 ×1；AI 只排序不打分（等级 + 理由），程序决定槽位。
4. **数字不背、原文标记**：纯数字/指标改为 `figure` 标注（阅读页高亮），不再生成卡片（卡片只出结构/任务/定位类）。
5. **关系标注由工作台人工创建**（AI 自动生成关闭：效果不可控）；箭头素材库（185 支）+ 样式面板全局配置。
6. **加量机制退役**：不再以"每天抓得越多越好"为目标；候选池规模服务于选材质量，不服务于发布数量。

## 不做什么

- 不做 embedding/向量/推荐系统（错误 0022 §11）；
- 不做 AI 自动归纳主线（人工维护）；
- 不做 AI 定稿选材（编辑判断交给工作台确认）。

## 后果

- `curation.py` 每日产物：`picks.json`（槽位/精选）+ 文章回写 `policyLine`/`aiCards`；
- 质量门禁：picks 缺失/为空 + 卡片/关系失败 → `degraded`（不阻止原文发布）；
- 线上站首页重构与复习流统一（TASK-0025/0026 继续）。
