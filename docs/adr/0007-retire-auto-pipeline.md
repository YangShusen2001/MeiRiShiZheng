# ADR 0007：自动聚合管道退役，转向策展内容

- **日期**：2026-08-20
- **状态**：已接受

## 背景

产品定位从「每日时政新闻站」收敛为「**广东考生 + 时政记忆**」工具。自动聚合管道（抓取 → AI 审核 → 质量门禁 → 发布）的产出是「每日新闻流」，与「知识体系 / 记忆工具」的定位不符——它消耗了大部分精力，却产出用户最不满意的"每天一堆低价值文章"。数据源体检（`docs/proposals/0021` 前置调研）证实：firehose 源噪声率 48%~59%。

## 决策

1. **停用自动聚合管道**：`sources.py` / `clip.py` / `review_agent.py` / `quality.py` / `review/` 等代码**保留不删**（git 历史可追溯），只是不再每日运行。
2. **停用唯一触发入口**：`启动审核.bat` 改名为 `启动审核.bat.disabled`，标记退役。
3. **内容改为策展产出**：人工（+ AI 辅助提炼考点/标注原文）产出精读与考点卡片，走 `content/` 静态内容，不再依赖运行时抓取。
4. **首页从「今日要闻」转为「今日待复习」**（记忆工具的面孔），新闻流降级为次要。

## 后果

- **好**：精力从"调管道/挑噪声"转向"产出精品内容"；内容质量与"广东考生"相关性可控。
- **代价**：内容更新频率从"每日自动"降为"人工策展节奏"；AI 标注能力（DeepSeek 结构化输出）仍保留，但不再批量自动跑。
- **恢复方式**：若未来想恢复自动抓取，将 `启动审核.bat.disabled` 改回原名即可，pipeline 代码与 `content/schema/*.json` 契约均未删除。
