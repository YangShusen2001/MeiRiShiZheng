# 提案 0016：移动端体验优化（符合拇指操作直觉）

> **状态：已并入提案 0017（2026-08-20）。** 本文保留原文供追溯；移动端优化随 0017 整合版一并执行（触控 44px / 划线就近弹出 / 操作沉底等），见 `docs/proposals/0017-pc-redesign-animation.md` §6。待确认决策（就近弹出 vs 底部固定、底部 Tab）迁移至 0017 §9。

## 1. 现状审查（代码依据）

| 区域 | 现状 | 问题 |
|---|---|---|
| 导航 | 顶部汉堡菜单（展开为顶部下拉面板，`Base.astro` + `global.css` @media ≤768px） | 单手拇指在屏幕底部，够不到顶部菜单 |
| 阅读页划线工具栏 | `placeFloating` 移动端分支（width≤600）把工具栏**钉在底部全宽**，按钮 min-height 44px、横向滚动（`hl-toolbar`） | 选完文字，拇指要从选区上移到底部再回来，交互割裂；工具栏在底部但操作对象在文中 |
| 阅读页字体/模式工具栏 | `read-toolbar`（A−/A＋/字体/沉浸/全屏）+ AI 标注模式切换都在**页面顶部** | 顶部操作与「划线/阅读」分离，单手不便 |
| 「去除」按钮 | 浮动在标注文字旁（`hl-remove`，position:fixed 就近） | 移动端易误触、遮挡正文 |
| 每日一练选项 | `q-opt`：移动端单列，padding 6px 10px、font 13px，高度约 36px | **触控目标 <44px**（Apple/Google 无障碍建议 ≥44px） |
| 错题本选项 / 删除按钮 | `wq-opt` 同样约 36px；收藏/错题删除按钮 `btn--sm` | 同上，误触率高 |
| 底部安全区 | 划线工具栏与 tooltip 已用 `env(safe-area-inset-bottom)` | 其余底部交互未统一 |
| 全局 | 无底部 Tab 导航；主题切换在顶部小按钮 | 高频入口分散在顶部 |

## 2. 问题分级（按「不符合人体直观操作」排序）

### P0 · 高优先（单手可达 / 触控目标 / 交互割裂）
1. **触控目标 <44px**：`q-opt`、`wq-opt`、收藏/错题「删除」、`fav-filter` 标签 → 统一 min-height 44px（最小改动、收益最大）。
2. **划线工具栏与选区分离**：移动端固定在底部，选完文字拇指要往返 → 改为「就近弹出」（紧贴选区上方/下方，溢出再贴边），与原生选中菜单一致。
3. **阅读高频操作在顶部**：字体大小 A−/A＋、AI 标注模式切换对单手不友好 → 移动端沉到底部（复用现有底部布局）。

### P1 · 中优先（易误触 / 信息密度）
4. 「去除」误触 → 移动端改「点按后二次确认」或「长按呼出」。
5. 收藏/错题列表项**整行可点**（现状只有标题可点），删除操作给足触控区。
6. 主题切换按钮触控区放大。

### P2 · 可选（锦上添花）
7. **底部 Tab 导航**（首页 / 搜索 / 每日一练 / 收藏 / 我的）——移动端主流模式，但涉及全部页面布局，改动大。
8. 深色模式跟随系统（`prefers-color-scheme`）。
9. 阅读页字号记忆已有（localStorage），可加「进度条」。

## 3. 可行性建议（按成本排序）

### 第一批（低成本，可立即做）
- `global.css`：`q-opt`/`wq-opt`/`.btn`/`fav-filter` 统一 `min-height: 44px`；移动端 flex 布局保持。
- 阅读页：移动端把「A− / A＋ / AI 标注模式切换」移到与划线工具栏同一底部栏（复用 `placeFloating` 的底部定位逻辑）。
- 划线工具栏移动端：`placeFloating` 增加「就近弹出」分支（选区上方优先，溢出翻到下方），不再固定底部。

### 第二批（中成本）
- 「去除」改长按呼出 + 二次确认。
- 列表项整行可点、删除按钮 ≥44px。
- 底部安全区统一 `env(safe-area-inset-bottom)`。

### 第三批（大改，需确认）
- 底部 Tab 导航（重排所有页面 shell）。
- 深色模式跟随系统。

## 4. 待确认决策

1. **划线工具栏移动端交互**：就近弹出（推荐，符合原生习惯）还是保持底部固定（改动小）？
2. **底部 Tab 导航**：要不要上？（大改；上了之后顶部菜单可简化为「我的/更多」）
3. **首批范围**：先做「触控 44px + 阅读操作沉底 + 划线就近弹出」这三项，可以吗？
