# 提案 0004：收藏类型（文章/金句）与注释交互增强

- **状态**：待评审
- **日期**：2026-08-16
- **任务分解**：TASK-0015
- **范围**：`apps/api`（favorites 路由 + 迁移）、`packages/contracts`、`apps/web`（阅读页、收藏页、划线渲染）

## 背景

当前「收藏」是单一种类：阅读页「☆ 收藏本文」和选区工具栏「收藏」都写入同一张 `favorites` 表，没有区分「收藏整篇文章」与「收藏某句金句」；注释用原生 `prompt()` 输入、且注释无法在划线处悬停查看。这两处都是公务员备考场景下的高频需求，需要产品化。

## 设计决策

### 收藏类型（文章 / 金句）

1. `favorites` 表增加 `kind`（`article` | `quote`，默认 `article` 兼容旧数据）与 `quote`（金句文本，仅 `quote` 使用）。
2. 阅读页「☆ 收藏本文」→ `kind=article`；选区工具栏「收藏」→ `kind=quote`，`quote` = 选中文本、`url` = 来源文章、`title` = 文章标题。
3. **统一**跳转：文章收藏与金句收藏都存来源文章 `url`/`title`，收藏页点击均跳回来源文章（金句不定位到段落，最简版）。
4. 幂等/去重：文章按 `(owner, url)`；金句按 `(owner, url, quote)`（避免同一文章的多条金句被误判重复）。

### 注释交互

1. 点「注释」→ 浮动工具栏**上方**弹出内联输入框 + 「确认 / 取消」，替代原生 `prompt()`；编辑已有注释时预填原值。
2. 注释悬停查看：渲染时给带注释的 `<mark>` 加 `title`（原生悬停提示）。

## 实施阶段

### 阶段 A：数据模型与契约

- `favorites` 迁移新增 `kind` / `quote`。
- `packages/contracts` 的 `Favorite` 与 `favoriteCreateSchema` 同步。
- `apps/api/src/routes/favorites.ts` 按 `kind` 处理与去重。

### 阶段 B：前端

- 阅读页：工具栏「收藏」改为金句收藏；注释内联输入框 + 悬停 `title`。
- 收藏页：分组展示「文章收藏」与「金句收藏」。

### 阶段 C：测试

- API：文章/金句各自幂等、去重口径。
- Web：渲染带 `title` 的注释、e2e 注释输入流程。

## 验收标准

- [ ] 「☆ 收藏本文」写入 `kind=article`；工具栏「收藏」写入 `kind=quote` 且 `quote` 为选中文本。
- [ ] 同一文章可收藏多条不同金句，不误判重复；同一金句重复收藏幂等。
- [ ] 收藏页分组展示文章收藏与金句收藏，均可点击跳回来源文章。
- [ ] 点「注释」在浮动工具栏上方弹出输入框，确认后保存、取消不保存，编辑时预填原值。
- [ ] 悬停带注释的划线能看到注释内容。
