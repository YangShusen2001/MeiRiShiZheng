# 提案 0009：修复顶栏滚动「抽搐」（jitter）

- **状态**：待评审
- **日期**：2026-08-16
- **任务分解**：TASK-0019
- **范围**：`apps/web/src/layouts/Base.astro`、`apps/web/src/styles/global.css`

## 背景

上一轮给顶栏加了「滚动收缩」：`onScroll` 在 `scrollY > 8` 时给 `.top` 加 `.scrolled`，把顶栏高度从 64px 改成 52px、logo 50→28px、加毛玻璃。用户反馈：**往下滑动一点点、停止滚动后，顶栏会「抽搐」**（在收缩/展开之间来回跳）。

## 根因

`.top` 是 `position: sticky`（**在文档流内**），高度 64px 参与排版。

`.scrolled` 把它改成 52px，等于**文档流高度瞬间少了 12px**，正文内容随之整体上移 12px。当滚动位置恰好停在 8px 阈值附近时：

1. `scrollY > 8` → 加 `.scrolled` → 顶栏变矮 → 正文上移；
2. 正文上移后，当前滚动位置对应的内容发生变化，`scrollY` 读数可能落回 ≤8；
3. → 移除 `.scrolled` → 顶栏恢复 64px → 正文下移 → `scrollY` 又 >8；
4. 循环往复，配合 0.25s 的 `transition`，形成肉眼可见的「抽搐」。

一句话：**sticky 顶栏在滚动时改变自身高度 → 布局位移 → 阈值附近震荡。**

## 方案

### 方案 A（推荐，改动最小、根治）

顶栏高度恒定，只收缩 logo + 加毛玻璃：

- 去掉 `.top.scrolled { height: 52px }`，顶栏始终 64px。
- 保留 logo 字号收缩（logo 是 `position: absolute`，**不影响文档流**）和毛玻璃背景。
- 结果：无布局位移 → 无抽搐；视觉上 logo 变小 + 出现毛玻璃，仍有「紧凑感」。
- 这也是 shadcn / Vercel 顶栏的标准做法：**高度不变、只加背景**。

### 方案 B（保留「高度收缩」，改动更大）

`.top` 改 `position: fixed`（脱离文档流）+ `body` 加 `padding-top: 64px` 占位：

- 高度收缩不再引起文档流位移 → 无抽搐，且保留 64→52 的高度收缩。
- 代价：sticky→fixed、body 占位、移动端适配都要动。

### 方案 C（不推荐）

方向感知 + 迟滞（hysteresis）：向下滚过阈值才收缩、向上才展开、加大死区。能缓解，但不能根治（切换瞬间仍有 12px 位移）。

## 推荐

**方案 A**：一行改动、根治抖动，保留 logo 收缩 + 毛玻璃，无新增复杂度。

## 验收标准

- [ ] 向下滚动一点点、停止后顶栏不再抽搐。
- [ ] 滚动后 logo 收缩 + 毛玻璃背景仍生效。
- [ ] 顶栏仍固定（sticky），导航收起/展开行为不变。
