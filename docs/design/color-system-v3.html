一套被算过的色板

颜色不是挑出来的。关于色相、每一级灰阶、每一个标注底色，都先经过对比度实算与色相环冲突检验，再定值。这份色板服务三个端：手机、网页、以及本地审核后台。​

品牌色相

通过 与最近语义色「术语」相距 38.9°（阈值 30°） 距禁入区边界还剩 8.9°。

通过 对底色对比度 7.70:1（暖底） / 8.53:1（纸卡）（阈值 4.5:1） 两底都达 AA。

总判 当前色相可用作品牌色 两条硬约束是「与任一语义色 ≥30°」和「对底色 ≥4.5:1」，必须同时满足。

230° 靛青

通过两条硬约束

距最近语义色 38.9°（阈值 30°），两项都过。但要留意：距禁入区边界只剩 8.9°——将来新增任何语义色，都必须重算这个余量。

176° 墨青

否决：撞上成功松绿

与成功色 156° 只差 19.8°。品牌按钮会被读成「操作成功」，语义被污染。

355° 绛

否决：撞上危险朱红

与危险色 4° 只差 6.7°。品牌按钮会被读成「危险操作」，用户不敢点。

为什么推倒重做

三条实测出来的理由，不是审美偏好。

一、不达标就先修，不谈统一

原网页端四个主题的辅助色（日期、来源、序号）实测为 2.88 到 3.88 比 1，全部不到无障碍 AA 的 4.5。换暖墨之后，辅助色在暖底 5.70、纸卡 6.32，双底都过。

二、后台一直锚错了基准

审核后台是唯一使用第三方设计系统的一端，它的内联样式里硬编码的是主站默认色值；而主站真正渲染的却是暖纸主题。也就是说，后台的视觉基准，从来不是用户看到的那一套。

三、三端里只有手机端是真设计过的

逐条复算手机端的对比度审计表，数值全部成立，而且它主动标注了自己两处妥协。统一的意义不是让三端长得一样，是让另外两端都达到同一把尺子。

青青子衿，悠悠我心。

品牌色「靛青」不只是从色相环上解出来的空档，它同时是《诗经》里学子的颜色——青衿。 这款产品的用户就是青衿，所以这个色相既过了两条硬约束（距最近语义色 38.9°、对暖底 7.70:1）， 在语义上也站得住：宣纸暖底配靛墨，靛与朱批构成传统「朱墨对比」，而产品最核心的动作， 恰恰是给原文划考点。
