# 验收标准

## 首页文章卡片

- [ ] 显示文章标题、来源和分类。
- [ ] 点击文章标题或卡片进入阅读页面。
- [ ] 显示 80-120 字 AI 概括。
- [ ] AI 概括不添加原文没有的事实。
- [ ] AI 概括失败时仍显示基础文章信息和原文链接。

## 阅读页

- [ ] 显示标题、来源、发布时间和官方原文链接。
- [ ] 支持原文模式和 AI 标注模式。
- [ ] 原文模式不显示 AI 标注。
- [ ] AI 标注模式显示观点句加粗。
- [ ] AI 标注模式显示申论考点高亮。
- [ ] AI 标注模式显示政策术语下划线。
- [ ] 鼠标悬停政策术语显示 30-80 字释义。
- [ ] 鼠标移开后释义消失。
- [ ] 用户标注和 AI 标注分开存储和渲染。
- [ ] 删除用户标注不影响 AI 标注。
- [ ] AI 生成失败时仍可阅读原文。

## 内容管道

- [ ] 每个内容 JSON 通过对应 JSON Schema。
- [ ] AI 标注片段能定位到对应原文段落。
- [ ] 标注偏移有效，不能越界或跨段。
- [ ] 术语释义长度符合 30-80 字目标范围。
- [ ] 来源失败、内容异常减少和 AI 失败均有结构化记录。
- [ ] 质量门禁失败时不静默发布。

## 账号和邮件

- [x] 只接受 QQ 邮箱验证码登录。
- [x] 验证码过期或重复使用时不能登录。
- [x] 验证码请求具备邮箱、IP 和设备限流。
- [x] 登录状态使用安全 Cookie。
- [x] 每日摘要只发送给已验证且主动订阅的用户（本地代码和测试）。
- [x] 同一用户同一期日报最多发送一次（本地幂等测试）。
- [x] 支持退订、失败记录和重试（本地 provider contract 测试）。

> 以上勾选表示仓库本地实现和测试通过，不代表 newsletter provider 或生产部署已完成。生产部署已于 2026-09-16 实测验证并关闭（`docs/release-verification-2026-09-16.md`）；newsletter provider 仍未完成，已降为 medium 记账、不阻塞发布。两个 blocker 见 `docs/release-readiness.json`。
