# MVP 范围

## 首期包含（0022 赛道转向后）

- 每日精选 2-5 篇（槽位制：头版要闻 / 申论精读 ×2 / 考点提炼 / 多样性补充；下限 2，历史补剧）。
- **人工维护主线池**（`content/policy-lines.json`）：active/retiring/archived 状态，决定"考什么"。
- 阅读页：原文 + AI 标注（观点/考点/术语/数字四类）+「连线」模式（默认关）：[ ] 中心句 + 荧光笔支撑句 + 手绘箭头。
- **关系标注工作台**（editor）：荧光笔画区 → [ ] 吸附 → 箭头素材库（185 支 + 上传）→ 上下方向 → 保存（.bak 备份）。
- **样式面板**：颜色/线粗/透明度/箭头尺寸/默认方向全局配置（线上站刷新生效）。
- 考点卡片（AI 提炼 + 人工确认）+ FSRS 间隔复习 + 每日一练改自卡片池。
- QQ 邮箱验证码注册/登录/登出；收藏；邮件订阅（生产投递证据完成前 blocked）。
- 内容质量门禁（含选材口径：picks/卡片失败 → degraded）+ 结构化日志。

## 首期不包含

- embedding / 向量库 / 个性化推荐算法。
- AI 自动归纳主线、AI 自动定稿选材、AI 自动生成关系标注。
- 用户名密码登录、社交登录、用户发布内容、微服务拆分。

## 降级原则

- 单篇 AI 处理失败：仍发布原文（标注缺失/降级）。
- 卡片/关系提炼失败：degraded，不影响原文发布。
- 选材失败（picks<1）：degraded，人工在审核台补选。
- 单来源失败 / 邮件单收件人失败：记录原因，不影响其他内容。
