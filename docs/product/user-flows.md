# 用户流程

## 复习与学习（首页三块）

```text
打开首页
  -> 今日待复习（FSRS 到期卡，软闸门遮罩）
  -> 翻卡自测（4 档自评）
  -> 今日精读 2-5 篇（槽位制精选）
  -> 阅读页：AI 标注模式查看标注；「连线」模式查看论证结构（默认关）
  -> 今日新增考点卡片
```

## 阅读与连线

```text
进入阅读页
  -> 原文模式 / AI 标注模式切换
  -> 打开「连线」：中心句 [ ] 圈、支撑句荧光笔、手绘箭头（默认关）
  -> hover/点击中心句查看该簇；数字/指标 figure 高亮标记（不背）
  -> 点击官方原文链接查看来源页面
```

## 内容运营（每日，人工+工作台）

```text
python -m kaogong.review（本地审核台）
  -> 抓取/剪藏/AI 标注
  -> 选材工作台（picks 槽位确认、主线归属改正）
  -> 关系编辑器：荧光笔画支撑句 -> [ ] 吸附中心句 -> 箭头库自选/上传 -> 上下方向 -> 保存
  -> 样式面板（全局样式）
  -> 质量门禁（picks/卡片失败 degraded）
  -> astro build 发布
```

## QQ 邮箱登录

```text
输入 @qq.com 邮箱 -> 请求验证码 -> 输入验证码 -> 创建或登录账号 -> Session Cookie
```

验证码请求不得泄露邮箱是否已注册。

## 用户标注与收藏

```text
选中文本 -> 荧光笔/下划线/注释 -> 保存用户标注（与 AI 标注互不覆盖）
收藏（登录=云端 / 未登录=本地）；术语收藏可点击
```
