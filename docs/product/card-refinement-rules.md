# AI 卡片提炼规则（0022 阶段 B，2026-08-22 拍板）

## AI 负责的内容

1. 从精选文章中提炼「必记考点卡片」（一问一答、原子、硬考点）。
2. 按文章类型路由模板：默认 A（通用），文件/报告类走 B，评论/时评类走 C。
3. 每张卡给出出处锚定（`anchor`：段落下标 + 原文连续子串）。

## AI 不负责的内容

- 不改写原文、不补充文章外事实、数字、政策结论。
- 不生成开放论述题（"谈谈你的理解"类）。
- 不生成完整申论范文。
- 不决定卡片是否发布——发布由人工在工作台确认（工作台为阶段 C）。

## 模板路由

| 文章类型 | 判定信号（程序侧，非模型判断） | 模板 |
| --- | --- | --- |
| 文件/报告/规划类 | 来源为政府门户/部委发文，或标题含「规划/意见/通知/报告/方案/批复/决定/办法/条例」 | B（数字记忆强化） |
| 评论/时评/解读类 | 来源为评论类栏目（南方时评/人民网评/半月谈评论等），或标题含「评论/时评/点评/解读/观察」 | C（申论表达） |
| 其他 | 兜底 | A（通用） |

路由是纯规则判定（`route_card_variant`），AI 不参与选模板，避免"模型自我感觉是文件类"造成的不一致。

## 模板差异（与 `pipeline/src/kaogong/card_ai.py` 的 `_VARIANT_RULES` 保持一致）

基础规则（A 通用，全部模板共用）：

1. 原子：一张卡只考一个考点（一问一答），禁止多考点揉进一个问题。
2. 硬考点：官方定位/原则/目标/提法/数字/单位/日期；禁止开放论述题。
3. 表述忠实：问题与答案只用文章中的事实/数字/官方表述，不得补充文章外信息。
4. 可锚定：`anchor.sentence` 必须是文章某自然段的原文连续子串（可跨分句，不可跨段），程序逐字定位，失败整卡作废。
5. 数量 3-8 张，宁缺毋滥；tags 1-5 个（从「定位/原则/目标/数字/任务/术语/要求/意义」中选，可加一个自定义词）。

**B 文件类加约束**：

1. 考点优先级：数字与目标（GDP 增速、指标值、覆盖范围、时间节点）> 结构性提法（如「两个同步」）> 任务清单。
2. 数字卡单独成卡：一张卡只问一个数字或一组强关联数字，禁止多个数字打包。
3. 答案中的数字必须与原文逐字一致；原文用区间（如「4.5%—5%」）时答案保留区间写法。
4. 含「新增/首次/达到/突破」等强记忆词的表述优先成卡。
5. 卡数目标 3-5 张：文件类考点应当充足；文章含明确数字目标（指标/增速/范围/节点）且未成卡时，必须补一张数字卡后再收尾。

**C 评论类加约束**：

1. 重点提炼「可直接用于申论写作的规范表述」，而非新闻事实；判断标准：考生能否直接引用/化用。
2. 表达卡格式：question 问「如何表述某观点/某关系」，answer 给出原文中最凝练的一句（≤2 句拼接，中间用「；」）。
3. 禁止提炼「作者态度」之类主观卡。
4. 文章的 keySentences 若出现在原文中，必须优先成卡。

## 卡片质量基准（黄金样本）

```
question：「十五五」时期的官方定位是什么？
answer：基本实现社会主义现代化「夯实基础、全面发力」的关键时期，具有承前启后的重要地位。
tags：定位, 关键时期
```

- 原子：一张卡一个考点。
- 硬考点：官方定位/原则/目标/提法/数字/单位/日期；不搞开放论述。
- 表述忠实：问题与答案只用文章中的事实/表述与官方表述，不得补充文章外信息。

## 输出协议

AI 返回 JSON（无 Markdown/HTML 包裹）：

```json
{
  "cards": [
    {
      "question": "正面问题（主动回忆）",
      "answer": "反面答案",
      "tags": ["定位"],
      "anchor": { "paragraphIndex": 0, "sentence": "原文连续子串" }
    }
  ]
}
```

程序必须：

- 校验 `question` 10-40 字、`answer` 6-200 字、`tags` 1-5 个（下限按人工黄金样本校准：数字卡答案最短 6 字、问题最短 10 字）。
- 在对应段落逐字定位 `sentence`（复用 `_locate`：先精确后折叠空白；失败整卡作废并记 `locationErrors`）。
- 丢弃无法定位或字段非法的单卡，不整篇作废。
- 为每张卡生成 `id`（`card-{articleId}-{n}`），`policyLine` / `examPointId` 由程序回填（`examPointId` 阶段 B 允许空）。
- 每篇卡数 0-8，宁缺毋滥。

## 每日上限（用户拍板 2026-08-22）

- **每日有效新卡 ≤5 张**，沿用 0021 拍板（每日新卡上限 5）。
- 超出部分丢弃（按文章顺序、文内顺序截断），不跨日补发。
- 到期复习卡不受此限（只限新卡）。

## 失败降级

- 卡片提炼失败不阻止文章发布原文：`aiStatus` 不变，卡片字段缺失或 `aiCards: []`，问题记录进当日报告（`aiCardErrors` 计数）。
- 卡片与关系标注（`aiRelations`）独立门禁、独立失败，互不牵连。

## 门禁

- 卡片锚定必须能定位（与 AI 标注同一套 UTF-16 偏移哲学）。
- 每篇卡数、每日总卡数（含跨文章累计）都有硬上限。
- 门禁必须有自动化测试（pipeline/tests/test_card_ai.py）。
