# 公开版本与内部开发

本仓库是 `YangShusen2001/MeiRiShiZheng` 的公开版本，默认分支为 `public-release`。

- 本仓库保留经审阅的公开源码、测试、示例及公开说明。
- 内部开发、需求规格、任务进度与内部技术记录保存在单独的私有仓库，以内部 `main` 为主线。
- 内部变更按文件白名单检查后单独导出提交，不合并私有提交历史；公开版本不承诺与内部进度即时一致。
- 账号、密钥、真实环境配置、会话和运行数据不进入公开提交；环境变量通过已脱敏示例说明。

2026-10-27 完成双仓库分工。本次公开提交只更新分工与导航，不更新运行代码，也不部署线上版本。旧公开 `main` 的历史先保全到私有归档，再移除公开分支。

分支不是隐私边界：同一个公开仓库里的所有分支都公开。后续内部内容仅在私有仓库维护。
